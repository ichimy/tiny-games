# Tiny Games 游戏库扩充设计

日期：2026-10-27

## 目标

把 Tiny Games 从单组幼儿触屏游戏扩展成可持续维护的家庭游戏库：

- 保留“无广告、不追踪、免登录、可离线”的底线。
- 首页按“幼儿玩”和“全家玩”组织游戏。
- 首批新增 6 个游戏，其中 3 个偏幼儿互动，3 个偏家庭轮流/猜词。
- 把现有 Unicorn Sky Rush 正式纳入游戏库。
- 为第三方开源游戏建立固定的来源、提交版本、许可证和改编记录。

## 非目标

- 不联网实时对战，不接入账号、排行榜或分析服务。
- 不批量打包来源不明的“开源游戏合集”。
- 不要求运行时安装依赖或执行构建命令。
- 不自动跟随上游更新；每个导入版本必须显式升级并重新验收。

## 目录与数据模型

新增 `games/registry.js` 作为运行时唯一游戏目录：

```js
self.TINY_GAMES_CATALOG = [
  {
    id: "say-it",
    title: "你说我猜",
    description: "全家轮流描述，看看一分钟能猜中几个",
    category: "family",
    emoji: "🗣️",
    path: "./games/say-it/",
    tags: ["全家玩", "猜词", "计时"],
    players: "2–8 人",
    source: {
      repo: "https://github.com/karlromets/molu",
      commit: "ce52930a0d4880ce367c6d96e46f61f1860afcb4",
      license: "MIT"
    },
    files: [
      "./games/say-it/",
      "./games/say-it/index.html",
      "./games/say-it/say-it.css",
      "./games/say-it/say-it.compat.css",
      "./games/say-it/say-it.js",
      "./games/say-it/og-image.png"
    ]
  }
];
```

约定：

- `id` 唯一，并与目录名一致。
- `category` 只能是 `toddler` 或 `family`。
- `path` 与 `files` 使用相对路径，站点可以部署在任意子路径。
- `source` 为原创游戏时写 `{ type: "original", license: "MIT" }`。
- 第三方游戏的新代码仍可按 MIT 分发，但必须保留上游许可证和署名。

## 首页

首页继续使用静态 HTML、CSS 和原生 JavaScript，不引入框架或运行时构建。

1. 加载 `games/registry.js` 后由 `script.js` 生成游戏卡片。
2. 分类按钮提供“全部 / 幼儿玩 / 全家玩”，默认显示全部。
3. 卡片显示中文标题、英文副标题、简介、玩家数、分类和操作标签。
4. 第三方改编游戏显示“开源改编”，原创游戏显示“Tiny Games 原创”。
5. 保留背景动效、键盘焦点、`prefers-reduced-motion` 和触屏大按钮。
6. 提供 `<noscript>` 基础链接，保证禁用 JavaScript 时仍能找到游戏入口。

## 离线缓存

`sw.js` 使用 `importScripts("./games/registry.js")` 读取目录：

1. 缓存应用外壳、字体和图标。
2. 遍历每个游戏的 `files`，预缓存全部运行资源。
3. 安装阶段使用 `Promise.allSettled`，单个资源失败不阻断其余游戏。
4. 缓存版本提升到 `v2`；目录或资源变化时必须再次提升版本。
5. 第三方游戏不得依赖 CDN、远程字体、远程音频或网络 API。

## 许可证与来源

新增：

- `THIRD_PARTY_NOTICES.md`：列出全部上游项目、固定提交、MIT 许可证和网站链接。
- `games/<id>/UPSTREAM.md`：记录本游戏如何取用上游代码、做了哪些改编、哪些内容和素材为原创。
- `games/<id>/LICENSE`：原样保留涉及代码复制的上游许可证。

不直接使用上游项目中许可证不明确的美术、音频或角色素材。家庭猜词卡牌和中文幼儿文案重新编写；音效默认使用 Web Audio API 合成。

## 游戏交互边界

### 谁藏起来了

- 3×4 或 4×4 大卡片，点击翻两张。
- 匹配成功播放音效并保留卡片；失败延迟翻回。
- 无计时压力，提供重开按钮。

### 彩色魔法笔

- 点击或拖动生成圆、星、心、气泡等图形。
- 图形带有颜色、缩放和漂浮反馈。
- 提供大号“清空画布”按钮。

### 小小清理队

- 三个短关卡：收集落叶、清扫纸团、整理玩具。
- 点击或滑动命中目标，完成后自动进入下一关。
- 不设失败结算，避免幼儿因超时受挫。

### 你说我猜

- 选择词库和 60/90 秒时长。
- 每轮显示“把手机交给描述者”的准备页。
- 描述者看到词语，点击“猜中了”或“跳过”。
- 时间结束后显示本轮得分，可再次开始。

### 不能说

- 同屏设置两队名称。
- 轮换队伍，每轮显示答案和禁用词。
- 按钮为“猜对”“违规”“跳过”，分别影响分数和剩余时间。
- 只保存在当前页面内，不记录孩子身份。

### 猜词小侦探

- 选择 3、4 或 5 个字母的英语单词。
- 六次机会，键盘或屏幕按钮输入。
- 绿、黄、灰反馈同时提供文字或图标，避免只靠颜色。

## 错误与降级

- 目录缺字段、ID 重复、分类非法或文件不存在时，测试失败。
- 浏览器不支持 Web Audio 时静默降级为视觉反馈。
- `localStorage` 不可用时只保留当前会话，不阻塞游戏。
- Service Worker 安装时单个资源失败会记录警告，其他游戏仍可离线。
- 第三方代码若存在隐藏网络请求，发布前必须移除或停止导入。

## 验证

### 契约测试

- 所有 ID 唯一，目录名、入口与分类合法。
- 原有 7 个游戏全部在目录中。
- 每个第三方游戏包含固定提交、MIT 许可证和 `UPSTREAM.md`。
- `files` 中的本地路径全部存在。
- 游戏源码不包含 `fetch`、XHR 或远程资源引用，除非该引用已明确列入例外并验证不影响离线。

### 浏览器验证

- 首页分类筛选、键盘操作和禁用 JavaScript 的基础链接。
- 每个新游戏在 390×844 和桌面尺寸下完成一次核心循环。
- 首次加载后断网重新打开，首页和所有游戏仍能启动。
- 检查控制台无错误、无追踪请求和第三方网络请求。

### 回归验证

- 原有 6 个游戏的核心操作仍正常。
- Unicorn Sky Rush 可从首页进入并离线启动。
- `CACHE_VERSION` 与资源清单一致。
